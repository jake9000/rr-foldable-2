I want to create a userscript that modifies the display of a webpage. It will be run in mozilla firefox for android via the violentmonkey extension. 

The phone in question is a samsung z fold 8, and the purpose of the extension is to modify the chapter display when the device is unfolded in landscape mode. 

User experience: 
    When opening a chapter view of a story on royalroad.com (example: https://www.royalroad.com/fiction/160418/the-great-afterlife-bake-off-a-cozy-baking-competition/chapter/3228028/chapter-3-the-first-technical),
    on the folding phone in landscape view,
    the chapter content will be displayed in a dual column with page flipping instead of scrolling.
