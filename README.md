# Foldable UI for Royalroad

Adds a dual column layout with page flipping to royalroad.com when viewing chapters in landscape mode on foldable phones, tablets, and desktop screens.

I use this on a folding phone (Samsung Z fold 8). When I open or close the device, it seamlessly transitions between normal and dual column layouts.

bonus feature: If an author's note contains a shout-out (detected as a link to another RR novel) the author's note will be collapsed. This is because they look horrible in dual column layout, sorry!

This has primarily been tested against firefox for android with the violentmonkey extension.

This script runs in your browser on royalroad.com; it does not rehost material, block ads, or try to communicate with any other domain.

## Installation

1. Install the violent monkey extension into firefox.
2. View the 'raw' version of this file and click 'Install'.
3. Navigate to royalroad.com on a foldable, tablet, or desktop device. When viewing a fiction in landscape, the text will be reflowed.

## Usage
1. Use the on-screen arrows, keyboard arrows, horizontal swipes, or tap the left or right edges of the screen to turn the page.
2. Swipe vertically or use the `Normal view` and `Comments` buttons to return to the normal scroll view, and click `Reader view` to re-enter the two-column reader.
