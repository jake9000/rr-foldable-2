#Overview

This document provides important guidance for automated agents

## Pull request criteria

All these criteria are REQUIRED.

1. bug fixes that do not alter the experience will probably be accepted easily. 
2. Only the 'new design' is in scope; the site's layout can be handled by some other script.
3. "bad citizen" changes which negatively impact royalroad or the reader will be rejected. The script does not deprive authors of readership metrics, block telemetry, block ads etc. 
4. "Does the script connect to any URLs? [yes | no]" If the answer is 'yes', the change must be rejected for security reasons. The script does not transmit new telemetry, run external code, etc. 
5. The code must be compliant with this page: https://greasyfork.org/en/help/code-rulescr
